# Intake questions

Ask all of these in one message before writing anything. Mark which answers are required.

## Required
1. **Language:** Python or R?
2. **Style source:** a template notebook or an existing notebook whose style the new notebook should follow (path or URL). If you have none, I will use a minimal default style and show it to you first.
3. **Environment:** is there an environment file the notebook must run in (`environment.yml`, `requirements.txt`, `renv.lock`, `DESCRIPTION`)? If not, I will create one after the notebook runs.
4. **Storyline:** please fill in the storyline template (`storyline-template.md`) or answer its questions here:
   - Goal: what should the notebook achieve?
   - Learning outcomes: what can the reader do afterwards?
   - Audience: who reads it, and what do they already know (programming, the data, the domain)?
   - Topic and context: the scientific or technical background in a few sentences.
   - Data: which dataset(s), from where, how they are accessed, and whether credentials are needed.
   - Sections: what each section should do and show. If you prefer, I can propose this after we agree on the agenda.
5. **Output:** file name and folder for the notebook. Should I deliver it executed with outputs (default) or with outputs cleared?
6. **Licence (required, no default):** under which licence will the notebook be published (for example MIT, Apache-2.0, CC-BY-4.0)? I cannot start without your answer. I will choose packages that fit it and check every package before hand-over.

## Optional
7. Length or time limit (for example "about 20 minutes to work through").
8. English variant (British or American) and any terms that must be used or avoided.
9. Copyright line, authors and organisation for the notebook metadata.
10. Related notebooks to link to (previous, next, further reading).
11. Where the notebook will run (laptop, JupyterHub, Binder, Colab) and any resource limits.
